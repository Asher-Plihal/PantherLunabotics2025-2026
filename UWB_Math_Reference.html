UWB Localization — Math Reference

PantherLunabotics 2025–2026  •  Florida Institute of Technology

What It Does

Two UWB anchors are fixed to the arena walls at known positions. Two UWB tags ride on the robot, one on the left and one on the right, separated by a known distance $W$. Each tag ranges to both anchors independently, producing four distance measurements per cycle: $d_{LA},\,d_{LB},\,d_{RA},\,d_{RB}$.

From those four measurements the system computes the full robot pose $(\,x,\;y,\;\theta\,)$ — position and absolute heading — with no IMU required. The heading is derived entirely from UWB geometry because the tags are labeled (left vs. right). With 4 measurements and only 3 unknowns the system is over-constrained, giving a built-in consistency check.

Coordinate System

$+X$ = east (right across arena). $+Y$ = north (away from berm, up the arena). Origin at the bottom-left corner of the arena. Heading $\theta$: $0°$ = north, positive = clockwise: $90°$ = east, $180°$ = south, $270°$ = west.

At heading $\theta$, the robot's right-lateral unit vector is $(\cos\theta,\;{-}\sin\theta)$. Therefore TAG_RIGHT is always displaced from the robot center in that direction, and TAG_LEFT is displaced in the opposite direction $({-}\cos\theta,\;\sin\theta)$.

Step 1 — Trilaterate Each Tag

Each tag's 2D position is determined by intersecting two circles: circle A (centered at Anchor A, radius $r_1$) and circle B (centered at Anchor B, radius $r_2$). Two circles in general position intersect at exactly two points that are mirror images across the A→B line.

Perform this procedure once for TAG_LEFT $(r_1 = d_{LA},\; r_2 = d_{LB})$ and once for TAG_RIGHT $(r_1 = d_{RA},\; r_2 = d_{RB})$.

Anchor separation

Precomputed once per session
$$d_{AB} \;=\; \sqrt{(b_x - a_x)^2 + (b_y - a_y)^2}$$

Projection distance along A→B

Derivation: subtract the two circle equations to eliminate x²+y²
$$a \;=\; \frac{r_1^2 \;-\; r_2^2 \;+\; d_{AB}^2}{2\,d_{AB}}$$

$a$ is the coordinate of the intersection points projected onto the A→B axis, measured from Anchor A. It comes from writing $|P - A|^2 = r_1^2$ and $|P - B|^2 = r_2^2$, then subtracting to cancel the quadratic terms, which leaves a linear equation in the projection of $P$ onto A→B.

Half-chord (perpendicular offset)

Pythagorean theorem in the local circle frame
$$h \;=\; \sqrt{\,\max\!\bigl(r_1^2 - a^2,\; 0\bigr)\,}$$

$h$ is the perpendicular distance from the A→B axis to each intersection point. The $\max(\cdot,\,0)$ clamp absorbs UWB noise that would otherwise produce a negative radicand when the circles barely touch. If $d_{AB} > r_1 + r_2$ (circles too far apart) or $d_{AB} < |r_1 - r_2|$ (one circle inside the other), the circles do not intersect — discard the measurement.

Intersection points in arena coordinates

Foot of perpendicular on the A→B line
$$P_x \;=\; a_x \;+\; a\,\frac{b_x - a_x}{d_{AB}} \qquad P_y \;=\; a_y \;+\; a\,\frac{b_y - a_y}{d_{AB}}$$
Unit vector perpendicular to A→B (rotated 90° CCW from A→B)
$$Q_x \;=\; -\frac{b_y - a_y}{d_{AB}} \qquad Q_y \;=\; \frac{b_x - a_x}{d_{AB}}$$
Two candidate positions (symmetric about A→B)
$$\text{Candidate 1:}\quad (P_x + h\,Q_x,\;\; P_y + h\,Q_y)$$ $$\text{Candidate 2:}\quad (P_x - h\,Q_x,\;\; P_y - h\,Q_y)$$

Step 2 — Select the Valid Pair

Step 1 produces two candidates for TAG_LEFT and two for TAG_RIGHT, giving four possible (L, R) combinations. The physically correct pair is the one where the tags are separated by exactly $W$.

Test all four (L_cand, R_cand) combinations
$$\text{sep} \;=\; \sqrt{(r_x - l_x)^2 + (r_y - l_y)^2}$$ $$\text{Accept the pair where } |\,\text{sep} - W\,| \;<\; \varepsilon \quad(\varepsilon \approx 0.05\text{ to }0.10\text{ m for UWB noise})$$

Normally exactly one pair passes. If two pairs pass (rare; occurs near the anchor-to-anchor diagonal where both mirror solutions have similar separations), select the candidate closest to the previous position estimate. If no pair passes, the reading is invalid — skip it.

Step 3 — Robot Center

Midpoint of the two tag positions
$$x_M \;=\; \frac{l_x + r_x}{2} \qquad y_M \;=\; \frac{l_y + r_y}{2}$$

If $f = 0$ (tag midpoint is at the robot's geometric center), then $(x,\,y) = (x_M,\,y_M)$. If the tag midpoint is mounted $f$ metres ahead of the robot center, apply the correction after computing $\theta$ in Step 4:

Forward-offset correction (apply only when f ≠ 0)
$$x \;=\; x_M \;-\; f\sin\theta \qquad y \;=\; y_M \;-\; f\cos\theta$$

Derivation: the forward unit vector at heading $\theta$ is $(\sin\theta,\,\cos\theta)$ in the north-0°-CW system. Subtracting $f$ times that vector steps backward from the tag midpoint to the robot center.

Step 4 — Heading

The vector from TAG_LEFT to TAG_RIGHT always points along the robot's right-lateral axis. At heading $\theta$, the right-lateral unit vector is $(\cos\theta,\,-\sin\theta)$, so:

Tag-to-tag displacement
$$v_x \;=\; r_x - l_x \;=\; W\cos\theta \qquad v_y \;=\; r_y - l_y \;=\; -W\sin\theta$$
Heading — invert the lateral-vector equations
$$\theta \;=\; \mathrm{atan2}(-v_y,\; v_x) \cdot \frac{180°}{\pi} \quad\text{(standard two-argument arctangent)}$$ $$\text{Normalize: if }\theta < 0°\text{ then }\theta \mathrel{+}= 360°$$

The first argument of $\mathrm{atan2}$ is $-v_y$ (not $v_y$) because the heading convention is clockwise-positive, while $\mathrm{atan2}$ uses counter-clockwise-positive. Negating $v_y$ converts between the two conventions.

Verification at cardinal headings

$\theta = 0°$ (north): TAG_R is due east → $v_x = +W,\; v_y = 0$ → atan2(0, +W) = 0°  ✓
$\theta = 90°$ (east): TAG_R is due south → $v_x = 0,\; v_y = -W$ → atan2(+W, 0) = 90°  ✓
$\theta = 180°$ (south): TAG_R is due west → $v_x = -W,\; v_y = 0$ → atan2(0, −W) = 180°  ✓
$\theta = 270°$ (west): TAG_R is due north → $v_x = 0,\; v_y = +W$ → atan2(−W, 0) = −90° → 270°  ✓

Residual Ambiguity

Both $\text{Candidate}_1$ and $\text{Candidate}_2$ from Step 1 satisfy the distance equations exactly. The W-constraint in Step 2 normally eliminates one candidate from each tag, leaving a unique solution. When the robot lies near the A–B axis, two (L, R) pairs can both satisfy the W-constraint. Resolution options:

  • Previous position — the robot cannot teleport; the correct candidate is always closest to the last known position. This is the primary tiebreaker in code.
  • Arena bounds — one candidate often falls outside $y \ge 0$ or the arena walls and can be discarded immediately.
  • IMU angular velocity — heading must change continuously between cycles. An IMU can confirm which heading is consistent with the recent turn rate.

Worked Examples

All cases: Anchor A at $(0,\,0)$,  Anchor B at $(4,\,0)$,  $W = 0.6\,\text{m}$,  $f = 0$.   $d_{AB} = 4.000\,\text{m}$ for all cases.

Because both anchors lie on the $x$-axis ($b_y = a_y = 0$), the perpendicular unit vector $\mathbf{Q}$ is always $(Q_x, Q_y) = (0, 1)$ for these examples. The two candidates for any tag therefore differ only in their $y$-coordinate: $(P_x,\, \pm h)$.

Case 1 — Robot at (2.000, 2.000), facing north (θ = 0°)  |  d_LA=2.625  d_LB=3.048  d_RA=3.048  d_RB=2.625

At θ = 0° the right-lateral axis points east (+X). TAG_LEFT = (2.000 − 0.300, 2.000) = (1.700, 2.000). TAG_RIGHT = (2.000 + 0.300, 2.000) = (2.300, 2.000).

Step 1a — Trilaterate TAG_LEFT  (r₁ = d_LA = 2.625, r₂ = d_LB = 3.048)
a = (2.625² − 3.048² + 4.000²) / (2 × 4.000)
= (6.891 − 9.290 + 16.000) / 8.000
= 13.601 / 8.000
= 1.700

h = sqrt(2.625² − 1.700²) = sqrt(6.891 − 2.890) = sqrt(4.001) ≈ 2.000

P_x = 0 + 1.700 × (4.000/4.000) = 1.700     P_y = 0
Q_x = 0, Q_y = 1

Candidate 1_L = (1.700 + 2.000×0, 0 + 2.000×1) = (1.700, 2.000)
Candidate 2_L = (1.700 − 0, 0 − 2.000) = (1.700, −2.000)
Step 1b — Trilaterate TAG_RIGHT  (r₁ = d_RA = 3.048, r₂ = d_RB = 2.625)
a = (3.048² − 2.625² + 16.000) / 8.000
= (9.290 − 6.891 + 16.000) / 8.000
= 18.399 / 8.000
= 2.300

h = sqrt(9.290 − 5.290) = sqrt(4.000) = 2.000

Candidate 1_R = (2.300, 2.000)     Candidate 2_R = (2.300, −2.000)
Step 2 — Select Valid Pair (W = 0.600 m, tolerance 0.05 m)
(1_L, 1_R): sep = sqrt((2.300−1.700)² + (2.000−2.000)²) = sqrt(0.360+0) = 0.600 ✓
(1_L, 2_R): sep = sqrt(0.360 + (2.000+2.000)²) = sqrt(0.360+16.00) = 4.045 ✗
(2_L, 1_R): sep = sqrt(0.360 + (2.000+2.000)²) = 4.045 ✗
(2_L, 2_R): sep = sqrt(0.360 + 0) = 0.600  (but y = −2.0 is outside arena) ✗
Accepted: TAG_LEFT = (1.700, 2.000), TAG_RIGHT = (2.300, 2.000). The mirror solution (2_L, 2_R) is discarded because y = −2.0 is outside the arena (y ≥ 0).
Step 3 — Robot Center
x = (1.700 + 2.300) / 2 = 2.000
y = (2.000 + 2.000) / 2 = 2.000
Step 4 — Heading
v_x = 2.300 − 1.700 = 0.600
v_y = 2.000 − 2.000 = 0.000
θ = atan2(−0.000, 0.600) = atan2(0, +) = 0.0° (north) ✓
x = 2.000 m    y = 2.000 m    θ = 0.0°
Sanity: Facing north means TAG_RIGHT is directly east of TAG_LEFT → v_x > 0, v_y = 0. Equal distances d_LA = d_RB and d_LB = d_RA confirm the symmetric straight-north configuration. The a-values (1.700 for TAG_LEFT, 2.300 for TAG_RIGHT) equal the x-coordinates of the tags, which makes sense because both anchors sit on the x-axis. ✓
Case 2 — Robot at (3.000, 1.500), facing east (θ = 90°)  |  d_LA=3.499  d_LB=2.059  d_RA=3.231  d_RB=1.562

At θ = 90° the right-lateral axis points south (−Y). TAG_LEFT = (3.000, 1.500 + 0.300) = (3.000, 1.800). TAG_RIGHT = (3.000, 1.500 − 0.300) = (3.000, 1.200).

Step 1a — Trilaterate TAG_LEFT  (r₁ = d_LA = 3.499, r₂ = d_LB = 2.059)
a = (3.499² − 2.059² + 16.000) / 8.000
= (12.243 − 4.240 + 16.000) / 8.000
= 24.003 / 8.000
= 3.000

h = sqrt(12.243 − 9.000) = sqrt(3.243) = 1.800

Candidate 1_L = (3.000, 1.800)     Candidate 2_L = (3.000, −1.800)
Step 1b — Trilaterate TAG_RIGHT  (r₁ = d_RA = 3.231, r₂ = d_RB = 1.562)
a = (3.231² − 1.562² + 16.000) / 8.000
= (10.439 − 2.440 + 16.000) / 8.000
= 23.999 / 8.000
= 3.000

h = sqrt(10.439 − 9.000) = sqrt(1.439) = 1.200

Candidate 1_R = (3.000, 1.200)     Candidate 2_R = (3.000, −1.200)
Step 2 — Select Valid Pair
(1_L, 1_R): sep = sqrt(0 + (1.800−1.200)²) = sqrt(0.360) = 0.600 ✓
(1_L, 2_R): sep = sqrt(0 + (1.800+1.200)²) = 3.000 ✗
(2_L, 1_R): sep = sqrt(0 + (1.800+1.200)²) = 3.000 ✗
(2_L, 2_R): sep = 0.600  (y negative, outside arena) ✗
Step 3 — Robot Center
x = (3.000 + 3.000) / 2 = 3.000
y = (1.800 + 1.200) / 2 = 1.500
Step 4 — Heading
v_x = 3.000 − 3.000 = 0.000
v_y = 1.200 − 1.800 = −0.600
θ = atan2(−(−0.600), 0.000) = atan2(0.600, 0) = 90.0° (east) ✓
x = 3.000 m    y = 1.500 m    θ = 90.0°
Sanity: Facing east means TAG_RIGHT is directly south of TAG_LEFT → v_x = 0, v_y < 0. −v_y = +0.600 > 0, vx = 0, giving atan2(+, 0) = 90°. TAG_LEFT (farther from Anchor A: d_LA=3.499) is north; TAG_RIGHT (closer: d_RA=3.231) is south — consistent with a robot facing east, since TAG_LEFT is to the robot's left (north when facing east). ✓
Case 3 — Robot at (1.000, 3.000), facing south (θ = 180°)  |  d_LA=3.269  d_LB=4.036  d_RA=3.081  d_RB=4.460

At θ = 180° the right-lateral axis points west (−X). TAG_LEFT = (1.000 + 0.300, 3.000) = (1.300, 3.000)  (to the robot's left = east). TAG_RIGHT = (1.000 − 0.300, 3.000) = (0.700, 3.000)  (to the robot's right = west).

Step 1a — Trilaterate TAG_LEFT  (r₁ = d_LA = 3.269, r₂ = d_LB = 4.036)
a = (3.269² − 4.036² + 16.000) / 8.000
= (10.686 − 16.289 + 16.000) / 8.000
= 10.397 / 8.000
= 1.300

h = sqrt(10.686 − 1.690) = sqrt(8.996) = 2.999 ≈ 3.000

Candidate 1_L = (1.300, 3.000)     Candidate 2_L = (1.300, −3.000)
Step 1b — Trilaterate TAG_RIGHT  (r₁ = d_RA = 3.081, r₂ = d_RB = 4.460)
a = (3.081² − 4.460² + 16.000) / 8.000
= (9.493 − 19.892 + 16.000) / 8.000
= 5.601 / 8.000
= 0.700

h = sqrt(9.493 − 0.490) = sqrt(9.003) = 3.001 ≈ 3.000

Candidate 1_R = (0.700, 3.000)     Candidate 2_R = (0.700, −3.000)
Step 2 — Select Valid Pair
(1_L, 1_R): sep = sqrt((0.700−1.300)² + 0) = sqrt(0.360) = 0.600 ✓
(1_L, 2_R): sep = sqrt(0.360 + (3.000+3.000)²) = sqrt(0.360+36.00) = 6.029 ✗
(2_L, 1_R): sep = 6.029 ✗
(2_L, 2_R): sep = 0.600  (y = −3.0, outside arena) ✗
Step 3 — Robot Center
x = (1.300 + 0.700) / 2 = 1.000
y = (3.000 + 3.000) / 2 = 3.000
Step 4 — Heading
v_x = 0.700 − 1.300 = −0.600
v_y = 3.000 − 3.000 = 0.000
θ = atan2(−0.000, −0.600) = atan2(0, −) = 180.0° (south) ✓
x = 1.000 m    y = 3.000 m    θ = 180.0°
Sanity: Facing south means TAG_RIGHT is directly west of TAG_LEFT → v_x < 0, v_y = 0. atan2(0, −) = 180°. The a-values confirm geometry: TAG_LEFT has a=1.300 (closer to Anchor A at x=0 by projection) and TAG_RIGHT has a=0.700 (even closer), matching that TAG_RIGHT sits at x=0.700 and TAG_LEFT at x=1.300. ✓
